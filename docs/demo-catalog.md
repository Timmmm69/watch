# Тестовый каталог часов

Для просмотра магазина подготовлены **8 товаров, 6 брендов, 3 категории,
29 часов на складе**. Одна модель с нулевым остатком показывает состояние
«Нет в наличии». Данные и фотографии иллюстративные: цены в BYN,
остатки и характеристики не являются реальным предложением.

## Запуск

На отдельной локальной базе выполните обычную настройку из
[local-development.md](local-development.md): установка зависимостей, PostgreSQL,
миграции. Для фото нужно S3-совместимое хранилище с уже созданным приватным
бакетом. В `.env` заполните `DATABASE_URL`, все пять `OBJECT_STORAGE_*`,
`PLATFORM_CURRENCY=BYN` и `INVENTORY_PROVIDER=native`.

```sh
pnpm demo:catalog
pnpm dev
```

Откройте `http://localhost:3000/shop`. Каталог и карточки доступны без входа;
для корзины, оформления и админки используется штатная авторизация Telegram.
Настройка бота и юридических документов остаётся по обычной инструкции проекта.

Команда сама создаёт валюту, поставщика, категории, активные товары, варианты,
медиа и начальные остатки через штатный журнал склада. Если валюта/поставщик
уже настроены, они сохраняются. Файлы фото включены в репозиторий и копируются
в ваше приватное хранилище; внешняя загрузка при просмотре не нужна.

Повторный запуск не добавляет дубли, не меняет карточки и не восстанавливает
потраченные остатки. Если загрузка фото/операция БД завершится ошибкой, изменения
в БД откатываются, загруженные файлы удаляются по возможности. Для полностью
нового демо используйте новую локальную БД и отдельный бакет.

Команда отказывается работать при `NODE_ENV=production` или если в базе уже есть
чужой каталог, заказы или начальные остатки. На рабочей базе её запускать не нужно.
Демопользователь нужен только для истории операций; прав администратора и сессии
у него нет. Закупочная стоимость оставлена неизвестной, а не вымышленным нулём.
