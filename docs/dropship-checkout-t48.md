# T48 — оформление заказа дропшиппером

В native-режиме (`INVENTORY_PROVIDER=native`) необходимы применённые миграции T46/T47, сверенный native-остаток, опубликованная карточка с D/фото/описанием и действующие документы условий/обработки данных. T48 проверена только локально; production и отгрузка не сертифицированы.

1. Открыть приложение через Telegram под своим аккаунтом дропшиппера. В кабинете принять текущие условия, если приложение этого требует.
2. Открыть каталог → карточку часов. Проверить материалы, SKU, цену дропу **D** и доступное количество. Нажать «Оформить заказ» у нужного SKU.
3. Указать целое количество **1–99** и цену покупателю за штуку **R**, не ниже D. Валюта — BYN, максимум два знака после точки или запятой. Сумма заказа — не больше **20 000 000.00 BYN**.
4. Проверить предварительные суммы: покупателю `R×q`, владельцу по D `D×q`, предполагаемая наценка `(R−D)×q`. Владелец получает всю сумму покупателя; наценка ещё не означает доступную выплату. Доставка согласуется отдельно.
5. Заполнить имя, телефон (8–15 цифр) и адрес получателя. Комментарий необязателен. Получателю не нужен Telegram. Ознакомиться с обработкой передаваемых вами данных и отметить поле формы.
6. Нажать «Оформить заказ». Если D изменилась, проверить обновлённые суммы и поставить «Подтверждаю новый расчёт по актуальной D», затем отправить снова. При необходимости повысить R.
7. Сохранить номер. Заказ и резерв созданы одновременно; оплата этим не подтверждается. Просмотр — «Мои заказы» → номер заказа. Там сохраняются D/R/наценка на момент оформления и данные вашего получателя. Изменение текущей карточки эти цены не меняет.

Если ответ потерян, повторить отправку **тех же данных в той же форме**: используется прежний ключ, второй заказ/резерв не создаётся. После успешного ответа не повторять новый заказ для исправления данных; связаться с оператором по номеру. Автоматическая редакция оформленного заказа в T48 отсутствует.

Блокировка/непринятые условия/недостаточное наличие не позволяют создать заказ. C, чужие заказы, чужие R и получатели дропшипперу недоступны. Старые Buyer/referral/cart пути новых заказов в native-режиме закрыты; исторические просмотры сохраняются.

**Остановлено перед T49:** завершённое оформление не включает native-отгрузку/физическую приёмку возвратов (T49), подтверждение денег и проверку условий доступности выплат (T50). Реальные заказы и платежи в приёмке T48 не проводились.
