# Дропшипперу

1. Открыть Mini App через утверждённого бота, войти своим Telegram и принять
   актуальные условия. Получателю аккаунт Telegram не нужен.
2. Выбрать SKU/вариант, проверить фото/описание/наличие и цену D. Использовать
   материалы для согласования с покупателем.
3. Ввести количество, явную цену покупателю R **за штуку**, имя/телефон/адрес
   получателя и комментарий. Передавать данные по утверждённым правилам, без
   вымышленного согласия получателя.
4. R>=D. Перед отправкой проверить суммы R/D и свою наценку R−D. Если D изменилась,
   подтвердить новый расчёт. Заказ фиксирует цены и резервирует часы, не подтверждает оплату.
5. Владелец получает всю согласованную R; оплату/доставку согласовать по его инструкции.
   Все продажи оформлять в приложении. При потере ответа повторить исходную форму;
   перед ручным дублем проверить «Мои заказы».
6. Следить за статусами; отмену до отправки/исправления и возврат после неё
   согласовать с владельцем через контакт поддержки. Чужие заказы/PII и C недоступны.
7. Наценка доступна после доставки, исходного hold, денежного покрытия и проверок
   Return. Доставлено не означает оплачено. Запросить доступный остаток при достижении
   показанного минимума (стандартная настройка 50 BYN).
8. Выплата ручная вне приложения, PAID ставится после перевода. Банковские пароли
   приложение не запрашивает. Частичный Return уменьшает наценку возвращённых единиц;
   поздний после выплаты создаёт долг, покрываемый следующим заработком.

Расходы владельца на упаковку/доставку автоматически не вычитаются из обещанной R−D.
